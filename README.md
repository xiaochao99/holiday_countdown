# 节假日检测插件

这个Home Assistant插件检测当前是否是中国法定节假日，并提供节假日相关信息。

## 功能

- 自动获取中国法定节假日数据
- 检测当前是否是节假日（开/关状态）
- 显示当前/下一个节假日名称和开始日期
- 显示放假天数
- 显示节假日剩余天数或距离下个节假日的倒计时
- 显示下一个节假日的名称
- 本地数据缓存减少API调用

## 安装

1. 确保已安装[HACS]
2. 在HACS中添加自定义存储库:
   - 仓库: https://github.com/xiaochao99/holiday_countdown
   - 类别: 集成
3. 安装"节假日检测"
4. 重启Home Assistant
5. 添加集成:
   - 转到 `设置` → `设备与服务` → `添加集成`
   - 搜索并添加"节假日检测"

## 配置

无需任何配置 - 添加集成后即可使用。

## 实体

安装后会创建一个实体：
- **sensor.holiday_sensor_cn**

### 实体状态

- **on**: 当前是节假日
- **off**: 当前不是节假日

### 实体属性

- **节假日名称**: 当前节假日名称（节假日时）或"非节假日"
- **放假天数**: 当前/下一个节假的放假天数
- **倒计时天数**:
  - 节假日时：剩余假期天数（如"剩余 3 天"）
  - 非节假日时：距离下个节假日的倒计时（如"距离 春节 还有 15 天"）
- **开始日期**: 当前/下一个节假日开始的日期
- **下一个节假日**: 下一个节假日的名称
